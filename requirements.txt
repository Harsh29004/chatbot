# Dependencies for `app.py` — the standalone Hugging Face Spaces demo.
#
# This is NOT the product's requirements file any more. The stack is three
# services now, and each declares its own:
#
#   bot-service/requirements.txt   retrieval, embeddings, sheet readers (Python)
#   node-backend/package.json      accounts, billing, admin, support (Node)
#   next-frontend/package.json     the web app (Next.js)
#
# What is left here is the demo Space: one file, no database, no API key, no
# other service. It loads the embedding model in memory, indexes a handful of
# pre-written FAQ rows per template, and answers from them — the same three-tier
# pipeline the product uses, with nothing around it.
#
# Install:  pip install -r requirements.txt && python app.py

# The demo UI. Only app.py uses this; the product has a React frontend.
gradio>=5.0.0

# The embedding model. Same one the product uses (all-MiniLM-L6-v2), so the
# demo's confidence scores mean what they do in the real thing.
sentence-transformers>=3.0.0

# A throwaway in-memory index, for the demo only. The product stores its
# vectors in MongoDB (see bot-service/backend/shared/vector_store.py) and does
# not depend on this.
chromadb>=0.5.0
